# 🔴 ИСПОЛЬЗУЙТЕ НА СВОЙ СТРАХ И РИСК

> [!CAUTION]
> **Возможны потеря данных, исходного серийного номера SN и MAC-адресов или их изменение.**
>
> На X115 при потере IMEI следует ожидать отказа мобильной сети и Galaxy Store. Wi-Fi и Bluetooth могут работать без IMEI, но после повреждения NV-данных это не гарантируется.
>
> **ТОЛЬКО SM-X115 — BIT 6 / U6. Не для другой модели или ревизии.**
>
> Исходная процедура применена 13 ноября 2026. Не подходит гарантированно для любого состояния устройства; не применять вслепую после A16.

## Краткая инструкция

1. Скачайте все четыре части .zip.001–.zip.004 в одну папку. Откройте .zip.001 в 7-Zip и распакуйте всё.

2. При необходимости установите VC++ и USB-драйверы из 03_DRIVERS. Для MTK: правой кнопкой по INSTALOVAT_MTK.cmd → Запуск от имени администратора.

3. Запустите 02_SP_FLASH_TOOL/SPFlashToolV6.exe.

4. Download-XML: выберите 01_SPFT_RECOVERY/download_agent/flash.xml. Authentication File: SM-X115_U3.auth из той же папки.

5. Выберите Download Only. Должны быть отмечены 17 строк с заполненными путями Location. Остальные параметры не меняйте.

6. Нажмите Download и подключите планшет по USB. Если он не определяется, удерживайте питание + уменьшение громкости до вибрации и отпустите. Не отключайте кабель во время записи.

7. После Download OK отключите USB. Для Download Mode удерживайте обе кнопки громкости и подключите USB; запрос подтвердите коротким нажатием увеличения громкости.

**При любой ошибке ОСТАНОВИТЕСЬ и не повторяйте ту же запись. Если Download Mode не появился, не запускайте новую запись.**

Затем прошейте официальный A15 BIT 6 через Odin: BL, AP, CP и CSC из 05_OFFICIAL_A15. CSC удалит данные. Re-Partition и Nand Erase выключены, PIT не выбран.
